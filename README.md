# how to install

1. clone the repo:
```bash
git clone https://github.com/MrKrot792/dots-2026
cd dots-2026
```

2. move all the files into your `.config` directory:
```bash
mv ./* ~/.config/
```

3. enjoy using it (it's designed for me, so you'll probably have a bad time)

btw i hardcoded in some values, so it won't work on every type of display
